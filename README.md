 Описание проекта

Проект представляет собой реалистичную пошаговую файтинг-симуляцию легендарного поединка.

Оба бойца выходят на ринг, имея по 100 HP. Сила удара каждого бойца варьируется от `1` до `5` единиц урона в зависимости от того, насколько успешно боец сфокусировал зрение в данный ход.

### ⚡ Ключевые особенности
* **Революционный Game Loop**: Движок полностью работает на бескомпромиссном цикле while.
* Сила каждого удара высчитывается квантово-случайным алгоритмом `random.randint(1, 5)`. 
* **Защита от отрицательного здоровья**: Внедрён передовой алгоритм `max(0, HP)`, гарантирующий, что боец не может иметь отрицательное количество жизней в сознании.
